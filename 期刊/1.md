Idea
1.当前主流闭环 RL 仿真现状大致分成三类：
第一类是 高保真重建环境路线，代表就是 RAD、ReconDreamer-RL：优点是视觉真实，缺点是训练重、交互 often 不够“真反应”、并且容易受原始数据分布限制。
 第二类是 数据驱动高速多智能体仿真路线，代表像 Waymax：优点是可大规模模拟、多智能体、吞吐高，缺点是通常偏 box/state level，不是 photorealistic sensor world。
 第三类是 latent/world model 路线，代表是 DreamerV3 这类 imagined RL 框架：优点是样本效率高，缺点是如果不回到高保真闭环评测，就会掉进“只在自己梦里赢”的问题

2.提出问题：（1）非反应式日志回放导致的伪闭环交互、（2）渲染在环带来的灾难性计算瓶颈，（3）以及传统整体式世界模型丢失决策关键细粒度信息的核心缺陷

3.提出pipline：
现有方法把自动驾驶 RL 建在高保真但交互不足、训练低效的环境上，而我们要用“决策充分的对象—关系世界模型”替代“渲染在环”，从而真正学会多车博弈并显著提升训练效率与长尾泛化

RAD问题详细描述
假闭环、假交互的核心缺陷，RL 无法学习真实交通博弈能力
论文明确采用 ** 日志重放（log-replay）** 控制环境中的其他交通参与者，即所有车辆、行人的轨迹完全是预定义的、固定的，不会对自车的动作做出任何动态响应。这导致：
- 自车的动作仅能改变自身位姿，无法影响环境状态的转移，构建的根本不是真正的闭环交互环境，RL 学到的只是「固定剧本下的避障」，而非真实驾驶中需要的交通博弈、礼让、应急交互能力；
- 论文定性实验中「礼让行人」的效果，只是模型学会了在固定时间点减速，而非学会了与行人交互，一旦真实世界中行人的轨迹发生变化，策略会直接失效。
2. 场景碎片化与探索空间锁死，完全违背 RL 的核心需求
- 论文为每个 8 秒片段重建独立的 3DGS 模型，没有全局统一的场景表示，RL 训练只能在碎片化的固定片段中进行，无法学习长时序、连续的驾驶决策；
- 3DGS 仅能在采集过的视角附近实现高保真渲染，一旦自车偏离专家轨迹，就会渲染出噪声图像，论文因此设计了「偏离阈值即终止 episode」的规则。这直接锁死了 RL 的探索空间，只能在人类专家轨迹附近做极小范围的试错，完全无法实现论文宣称的「通过大规模试错学习处理分布外场景」的目标，形成了核心逻辑矛盾。
3. 奖励信号失真与上帝视角信息泄露，进一步放大 sim2real 差距
- 论文的碰撞检测采用了双重标准：动态碰撞依赖标注的障碍物包围盒、静态碰撞依赖 3DGS 的高斯分布，均使用了「上帝视角」的全局信息，而非智能体从渲染图像中感知到的信息。这导致 RL 优化的是基于完美信息的决策，而真实世界中智能体只能通过带噪声、有遮挡的传感器感知，进一步拉大了仿真与真实世界的差距；
- 「触发碰撞 / 超偏差即终止 episode」的设计，虽然避免了噪声数据，但也导致 RL 无法从错误中学习，奖励信号极度稀疏，只能靠辅助目标补充，反而进一步限制了 RL 的探索能力。
4. IL 正则项的强约束，让 RL 失去了核心价值
消融实验明确显示，纯 RL 的效果远不如 RL+IL，甚至纯 RL 的轨迹一致性还不如纯 IL。这说明该框架中的 RL，根本无法从零学习到有效的驾驶策略，必须靠 IL 正则项严格约束在人类行为附近，只能做极小范围的微调，完全无法发挥 RL「通过试错学习超越人类专家策略」的核心优势，RL 沦为了 IL 的「补全工具」，而非核心的策略学习范式。
5. 动作空间解耦的设计缺陷，牺牲了复杂场景的决策能力
论文为了降低探索空间，将横向、纵向动作完全解耦，分开设计奖励、价值函数和 PPO 优化目标。但真实驾驶中，横向与纵向动作是强耦合的（如紧急避让需要同时转向 + 刹车），解耦设计导致模型无法学习这种耦合的最优决策。论文的实验结果也印证了这一点：RL+IL 的纵向加加速度（4.495）远高于纯 IL（3.928），驾驶平滑性更差，离散解耦的动作空间无法实现精准、平滑的连续控制。
6. 规模化落地能力几乎为零，训练成本极高
该框架的落地需要极高的前置成本：首先要采集海量的真实驾驶数据，然后对每个驾驶片段逐一做 3DGS 重建，再用数百张 GPU 完成三阶段训练。且 3DGS 场景无法跨场景复用，每换一个新的城市、新的道路，就要重新采集、重建、训练，算力、数据、时间成本极高，完全无法适配自动驾驶规模化落地的需求。


针对性主要问题
现有的基于3DGS的强化学习框架在工程落地时面临两个极其严峻的理论与系统瓶颈：计算重（Heavy Computation）与伪交互（Pseudo-interaction）。首先，在MDP（马尔可夫决策过程）的每一个时间步进行3DGS渲染和梯度反向传播，其计算开销是灾难性的。其次，现有环境中的其他交通参与者（Traffic Agents）多为回放代理（Replay Agents），它们遵循固定的日志轨迹，对自车（Ego-vehicle）的探索性行为毫无反应，导致智能体学习到极度保守甚至停滞的次优策略 ()。
为了彻底解决上述问题，提出了“决策导向的对象关系强化学习”（Decision-Oriented Object-Relational Reinforcement Learning, 简称doorRL）的方案。该方案摒弃了将3DGS渲染嵌入RL循环的低效做法，转而采用前馈4D重建（Feedforward 4D Reconstruction）提取对象Token，并在基于插槽注意力（Slot-Attention）的以对象为中心的世界模型（Object-Centric World Model）的隐空间中进行高并发的反应式（Reactive）强化学习训练。
核心挑战的深度剖析与旧范式批判
在设计doorRL的具体架构之前，必须深刻剖析现有“3DGS+RL”与“世界模型+RL”范式的固有缺陷，以便为后续的工程优化提供理论支撑。
2.1 渲染在环（Render-in-the-loop）的计算瘫痪
在RAD等框架中，为了提供高保真度的闭环环境，仿真器必须在RL智能体执行每个动作后更新视点并重新渲染整个3DGS场景 ()。尽管3DGS相较于隐式神经辐射场（NeRF）具有更快的渲染速度，但在动辄数百万步的PPO（近端策略优化）训练中，这种渲染在环的机制严重拖慢了样本采集的FPS（Frames Per Second）。
此外，现有的视觉RL方法通常依赖ResNet或标准Vision Transformers（ViTs）等卷积特征提取器来处理这些渲染出的原始图像 ()。这种做法不仅导致状态空间极度高维和冗余，还迫使RL策略网络在优化控制决策的同时，还要兼顾底层的像素级表征学习。这种耦合导致了巨大的探索空间，极大地降低了采样效率和收敛速度 ()。
2.2 伪交互（Pseudo-Interaction）对探索策略的毒害
在自动驾驶闭环仿真中，其他车辆和行人的行为逻辑对RL策略的成型至关重要。CARLA等传统仿真器或基于真实数据集（如Waymo、nuScenes）重建的3DGS场景，通常使用日志回放（Log-replay）机制来驱动交通参与者 ()。当RL智能体尝试执行如变道、超车等探索性动作时，回放的车辆并不会像真实人类驾驶员那样减速避让。这种非反应性（Non-reactive）的“伪交互”会导致不可避免的碰撞，从而对安全的探索行为施加不合理的惩罚 ()。
研究表明，单纯依赖固定轨迹的交通模拟会剥夺智能体学习高级博弈和避撞策略的激励，导致策略陷入局部最优——例如智能体可能会选择永远停留在原地以避免因变道引发的必定碰撞 ()。尽管CARLA中存在IDM（智能驾驶模型）等简单规则模型，但其表达能力不足以模拟复杂城市路况下的多智能体交互。
2.3 整体性世界模型（Holistic World Models）的细粒度特征丢失
以DreamerV3为代表的基于世界模型的强化学习（MBRL）通过在“想象的”潜在隐空间（Latent Space）中训练策略，极大地提高了样本效率 ()。然而，DreamerV3的循环状态空间模型（RSSM）学习的是整个环境的整体性（Holistic）表征，将所有视觉信息压缩为一个单一的潜向量 ()。
在复杂、动态的真实街道场景中，这种整体性表征往往会忽略对决策至关重要但占据像素面积较小的元素（例如远处的红绿灯、被部分遮挡的行人）()。由于基于 $$L_2$$ 范数的重建损失主要由占据大面积像素的背景主导，世界模型很难捕捉到个体对象之间的复杂物理与因果关系 ()。


DOOR-RL 方案实施路线图
执行摘要
DOOR-RL 针对近期基于 3DGS 的闭环自动驾驶强化学习系统的一个核心缺陷：这类系统虽能实现照片级真实感渲染，但智能体仍在非交互式交通流（日志回放）中学习，且依赖人工设计的动作离散化方案，限制了多智能体交互能力的学习。RAD 方法明确指出，其 3DGS 环境中其他交通参与者均以 “日志回放” 方式运行，同时为加速 PPO 训练，采用了刻意简化的短视程离散动作表示。
本文提出的工程策略为 **“梦境中训练，高保真现实中测试”：在令牌化对象 - 关系隐式世界模型中训练策略（高吞吐、基于模型 / 想象学习），再在高保真闭环仿真器 **（3DGS 与 CARLA/SMARTS）中评估，以此规避评估悖论。RAD 验证了高保真闭环评估的必要性，ReconDreamer-RL 则开源了基于 Gym 接口、搭载 nuScenes 重建场景的 3DGS 仿真器，为高保真测试提供了可行路径，无需复现 RAD 的完整环境栈。
一套兼具可行性与论文发表价值的 DOOR-RL 最小可行版本，将分阶段构建：
- MVP 阶段（4–6 周）：完成令牌化流程 + 专家策略蒸馏 + 以 DreamerV3 为蓝本的对象中心式世界模型（隐式想象），在交互式数据环境（SMARTS/Waymax）中训练，本地完成 CARLA 排行榜与 3DGS（基于 ReconDreamer-RL）评估。
- NeurIPS 级别扩展（6–12 周以上）：融入 DGGT/VGGT4D 的 4D 先验；引入关系不确定性建模（集成模型 / 分歧度）；开展系统性反事实压力测试与消融实验，验证三大核心设计的必要性：(1) 关系建模、(2) 专家引导的决策完备性、(3) 梦境到现实的迁移评估。
论文一句话定位：DOOR-RL 从 4D 先验中学习面向决策的对象 - 关系状态抽象，通过隐式想象训练交互式自动驾驶策略，并在高保真闭环仿真器（3DGS/CARLA）中验证性能，解决伪闭环交互与渲染循环算力消耗过大的基线问题。
问题定义与核心论点
精准问题描述
基于多传感器（或多相机）驾驶日志与交互式仿真 rollout 数据，学习端到端自动驾驶策略，使其在多智能体交互场景下最大化安全性与任务完成度，同时具备样本高效性与分布偏移鲁棒性，且评估严格依托高保真闭环测试，而非自构建的简化隐式环境。
形式化定义：学习策略 π(at∣st)，其中状态 st 为基于 4D 先验的对象 - 关系集合：st={et}∪{oti}i=1..Nt∪{mtj}j=1..Mt∪{rti→k}
- et：自车令牌；oti：动态智能体令牌；mtj：静态拓扑 / 地图令牌；rti→k：关系令牌（碰撞时间、路权、车道冲突、遮挡等）。
采用 DreamerV3 式隐式世界模型 pθ(zt+1,rt∣zt,at) 与想象轨迹 rollout 训练，即显式学习环境模型，将输入编码为离散表征，预测未来表征与奖励，并从想象轨迹中训练演员 - 评论家网络。
达到 NeurIPS 水准需验证的核心结论
一篇合格的 NeurIPS 论文需提出三个可证伪的核心论点，并设计实验直接验证：
1. C1（决策完备性抽象）：DOOR-RL 学习的状态抽象保留了高质量决策所需的全部关键信息（对比全令牌输入与启发式对象筛选）。
2. C2（交互真实性 vs 伪闭环）：在交互式（动态响应）环境中学习得到的策略，比非交互式日志回放训练的策略更安全、更符合交通社交规范；RAD 明确采用日志回放，因此 DOOR-RL 需量化二者性能差距。
3. C3（梦境到现实的迁移能力）：主要在隐式想象中训练的策略，迁移至高保真闭环环境（3DGS 与 CARLA）时性能可保留（甚至提升），避免 “模型仅在自造的梦境中有效”。
系统模块、接口与开源基线
必备模块与清晰接口
DOOR-RL 将工程化为可复现的流水线，定义明确接口，最小模块集如下：
- 令牌化器 + 规范 schema：将日志 / 仿真输出转换为固定格式、带掩码、归一化、统一坐标系的填充令牌张量与元数据。
- 4D 先验提取器（离线）：输出深度、位姿、动态掩码，可选输出 4D 高斯；用于丰富令牌特征、提供稳健的几何 / 运动先验（无需接入 RL 循环），可直接使用 DGGT 与 VGGT4D 开源方案。
- 教师 / 专家模型：提供动作与（可选）价值目标，解决训练初期的完备性冷启动问题；CARLA Garage 包含 “专家驾驶员” 与 Leaderboard 2.0 完整训练评估代码。
- 决策完备性抽象模块：学习筛选 / 聚合对象与关系，保证教师动作 / 价值可预测，后续通过 RL 微调。
- 对象 - 关系世界模型（DOOR-WM）：神经网络隐式动力学 + 奖励 + 终止信号 + 不确定性建模。
- 隐式想象 RL（DreamerV3 式）：在隐式空间中训练的演员 - 评论家，DreamerV3 代码库提供训练循环、配置文件与鲁棒的归一化 / 平衡技巧。
- 交互式数据环境：生成交互式 rollout 与 / 或离策略数据；SMARTS 是成熟的多智能体自动驾驶 RL 平台，仓库完善、文档齐全、采用 MIT 协议。
- 高保真评估环境：
  - CARLA 排行榜：标准化闭环评估场景（汇入、变道、交叉口、行人、天气变化）。
  - 3DGS 闭环：ReconDreamer-RL 开源基于 nuScenes 重建的 Gym 接口 3DGS 仿真器与环境服务启动脚本。

数据与 4D 先验提取流水线
选用数据集及理由
NeurIPS 级别论文需至少使用两类真实数据集 + 一类高保真仿真基准：
- nuScenes：多传感器数据集（6 相机、激光雷达、雷达、GPS/IMU），适配对象中心式令牌提取与地图拓扑先验。
- Waymo Open Dataset / Motion：大规模驾驶数据，DGGT 与 DriveRecon 提供下载 / 预处理流程；Waymax 支持可扩展框级仿真与指标计算。
- CARLA Leaderboard（搭配 carla_garage 路线 / 数据集）：标准化、可复现的高保真闭环评估，场景与天气多样化。
- 3DGS 评估：使用 ReconDreamer-RL 开源的 nuScenes 3DGS 场景 + Gym 仿真器，测试视觉真实感闭环行为。
DOOR-RL 标准令牌输出格式
定义全流程统一规范（日志、交互式仿真、想象空间通用），推荐标准张量（单时间步）：
- tokens：float32，形状 [S, D]，固定填充长度 S = 1 + Nmax + Mmax
  - S：总令牌数（自车 + 动态智能体 + 地图 / 拓扑点）
  - D：特征维度（建议原始 32–64 维，嵌入后 128–256 维）
- token_mask：bool，形状 [S]
- action：float32，形状 [A]（推荐连续动作，如 [加速度, 转角] 或 [目标速度, 偏航率]）
- reward, done, info：包含碰撞类型、驶离路面、行驶进度、场景标签等
- frame_meta：时间戳、归一化统计量、坐标系、数据集 ID
坐标系选择：所有位置 / 速度统一使用自车中心局部坐标系（x 向前、y 向左），保证策略在 nuScenes、Waymo、CARLA、3DGS 间泛化。
4D 先验提取具体方案与命令

模型架构与训练课程
架构总览
DOOR-RL 兼容 DreamerV3 “隐式想象” 范式，同时原生支持对象 - 关系建模：通过编码器 / 抽象模块生成紧凑隐式表征 zt，世界模型与演员 - 评论家完全基于隐式轨迹训练。DreamerV3 显式将感官输入编码为离散表征，学习预测未来表征与奖励，用于想象训练。
输入与形状定义
设定：
- S = 1 + Nmax + Mmax 令牌（建议 Nmax=32、Mmax=64，即 S=97）
- 原始令牌维度 D_raw=40（连续运动学 + 类别 + 置信度 + 标志位）
- 嵌入维度 D_model=256
- 动作维度 A=2（连续）或 A=3（如加速度、转角、目标速度）
- 抽象输出紧凑实体数 K=16 或 K=24
环境输出：
- x_t ∈ ℝ^{S×D_raw}、mask_t ∈ {0,1}^S、a_t ∈ ℝ^A
4D 先验提取模块
该模块为工程封装层，非核心创新点，按确定性（或缓存）预处理模块使用：
- DGGT 推理输出相机位姿与可选深度图。
- VGGT4D 输出深度、置信度、内参、轨迹、动态掩码。
接口：
- extract_priors(scene_dir) -> {depth[t,cam], conf[t,cam], poses[t], intrinsics[cam], dynmask[t,cam]}
- 磁盘缓存，按模型提交哈希 + 权重哈希版本管理。
融合专家蒸馏预训练的决策完备性抽象模块
该模块解决 “完备性冷启动” 问题：RL 训练初期策略 / 价值效果差，基于价值的完备性损失可能丢弃安全关键信息。解决方案为分阶段课程学习：先专家引导预训练（RAD 同样采用规划预训练 / 模仿学习实现稳定冷启动），再 RL 精调。
教师来源（专家）
至少选用一种可信专家：
- CARLA：carla_garage 内置 “专家驾驶员”，以及 Leaderboard 2.0 数据集 / 训练 / 评估基础设施。
- 3DGS / nuScenes：ReconDreamer-RL 提供基于数据集标注控制自车的 “人工策略”，可作为 3DGS 环境中的真值示范者。
抽象网络设计
简洁有效、易消融的设计：
- 令牌嵌入：逐令牌 MLP：D_raw -> D_model
- 类型编码：为 {自车、机动车、行人、非机动车、地图节点、信号灯} 学习嵌入，叠加至令牌特征
- 自车查询交叉注意力：自车令牌作为 Query 计算所有令牌的相关性权重 w_i
- 前向传播硬 Top-K 筛选 + 梯度稳定软注意力：
  - 计算 score_i = MLP(attn_out_i)
  - 选取智能体令牌中得分最高的 K 个，搭配 “强制保留规则”（碰撞时间低于阈值、最近行人等）
- 输出：
  - z_t_global ∈ ℝ^{D_model}（全局池化特征）
  - z_t_entities ∈ ℝ^{K×D_model}（筛选后的实体集合）
  - 筛选掩码 sel_mask ∈ {0,1}^K 与可可视化的重要性权重
损失函数
预训练（专家蒸馏）：
- 动作蒸馏：教师动作分布与学生输出的 KL 散度，连续动作使用 MSE。
- 价值蒸馏：学生价值与教师收益估计（示范数据蒙特卡洛收益或教师评论家输出）的 MSE。
- 辅助显著性：约束筛选权重匹配教师注意力或启发式 “风险显著性”（基于碰撞时间）。
RL 精调：保留小权重模仿正则项（RAD 同样在 RL 中使用模仿学习正则），训练过程中逐步降低权重。
带不确定性建模的对象 - 关系世界模型
世界模型需全神经网络可微，保证想象 rollout 稳定（不可在想象转移中硬编码规则逻辑），与 DreamerV3 设计一致：从经验中学习环境模型，从想象轨迹训练策略。
隐式状态结构
混合隐式表征：
- h_t ∈ ℝ^{D_h}：全局循环状态（如 512 维）
- u_t ∈ ℝ^{K×D_u}：单实体隐式槽位（如 K×256 维）
- z_t：随机离散隐式变量（DreamerV3 采用离散表征）
转移模型（对象 - 关系动力学）
实用实现方案：
- 构建作用于 [动作令牌, 实体令牌] 的关系 Transformer 模块：
  - action_token = MLP(a_t) ∈ ℝ^{D_model}
  - 拼接序列长度 K+1，带掩码多头注意力更新
  - 更新实体隐式特征，输出全局更新量用于 h_t
预测头
- 观测解码器：预测下一步实体运动学（均值 + 对数标准差），类别如需可输出分类对数几率。
- 奖励头：预测标量奖励分布（高斯或离散）。
- 终止 / 续行头：预测续行概率，DreamerV3 采用该设计用于想象 rollout。
- 不确定性：
  - 最简方案：5 个世界模型组成集成，测量奖励与碰撞概率的分歧度
  - 分歧度用作 (1) 风险估计 (2) 探索奖金（世界模型 RL 通用扩展范式，与 DreamerV3 后续集成分歧度的扩展一致）
世界模型损失
单时间步损失：
- L_obs：连续运动学与对象属性的负对数似然
- L_reward：奖励预测损失
- L_cont：续行二分类交叉熵
- L_KL：后验与先验隐式分布的 KL 散度（RSSM 范式）
- （可选）L_rel：关系特征辅助预测（碰撞时间分箱、车道冲突），提升关系校准精度

评估方案、消融实验与失效模式
梦境训练 - 高保真测试方案
为规避评估悖论，该方案为强制要求：
- 训练：主要在隐式想象空间与交互式数据环境（SMARTS/Waymax）中进行。
- 测试：在高保真闭环仿真器中执行，包括：
  - CARLA 排行榜：标准化场景与违章检测（汇入、变道、交叉口、行人、天气）。
  - 3DGS 闭环：使用 ReconDreamer-RL 的 nuScenes 3DGS 重建场景与 Gym 仿真器，其提供服务启动与策略部署脚本。
选用 CARLA + 3DGS 的原因：CARLA 可控性强、场景多样；3DGS 传感器特性更贴近真实日志（RAD 与 ReconDreamer-RL 均强调该动机）。
评估指标
全环境统一使用场景感知指标：
- 安全性：碰撞率（机动车 / 行人 / 静态障碍物）、近碰撞率（碰撞时间低于阈值）、驶离路面、逆向行驶。CARLA 排行榜内置违章式评估。
- 任务完成度：路线完成率、成功率、抵达目标时间。
- 舒适性：加加速度、横向加速度、急刹车次数。
- 交互质量：对他车的制动诱导、让行合规性、汇入协商成功率、切入射鲁棒性。
- 吞吐 / 样本效率：环境步数 / 秒、达到安全阈值耗时、基于模型的样本复用率（train_ratio）。DreamerV3 专为泛化鲁棒性与扩展设计，需报告训练比例与算力消耗。

- 关系消融：仅对象令牌（无 rti→k）vs 对象 - 关系令牌。
- 专家引导消融：无教师预训练 vs 教师蒸馏调度。

论文需撰写的失效模式与缓解方案
- 评估悖论：“仅在隐式梦境中有效”
  - 缓解：严格执行梦境 - 现实迁移评估，明确报告性能差距；禁止仅用隐式空间测试作为有效证据。
- 完备性冷启动：早期策略 / 价值错误 → 抽象模块丢弃关键信息
  - 缓解：专家蒸馏冷启动（教师动作、价值 / 收益）+ 安全强制保留规则（低碰撞时间智能体）。RAD 同样采用模仿学习正则保持人类对齐，可作为蒸馏项的先例。
- 规则 - 模型融合冲突：硬规则破坏可微想象 rollout
  - 缓解：想象动力学保持纯神经网络；用规则生成交互式 rollout 数据；可选软约束损失正则化世界模型，而非硬截断。DreamerV3 设计预期为学习型动力学。
- 世界模型复合误差（想象未来失真）
  - 缓解：多步预测损失；不确定性感知策略（惩罚高分歧度状态）；定期真实 rollout 更新回放池；训练初期短视程想象，逐步延长。
- 跨域令牌漂移（nuScenes vs CARLA vs 3DGS）
  - 缓解：自车中心归一化、类型嵌入、令牌级域随机化、跨域奖励 / 代价头校准。

标题DOOR-RL：面向交互式闭环自动驾驶的决策导向对象 - 关系世界模型
摘要（2–3 句）本文研究如何在无需渲染密集型仿真参与学习循环的前提下，训练具备多智能体交互推理能力的自动驾驶策略。提出 DOOR-RL 方法，将 4D 几何先验蒸馏为面向决策的对象 - 关系完备抽象，并在学习到的对象 - 关系世界模型中通过隐式想象训练演员 - 评论家策略。在梦境中训练的策略，于高保真闭环仿真器（CARLA 排行榜与基于 3DGS 的 nuScenes 重建场景）中评估，相较日志回放与无关系建模基线，展现出更优的安全性与鲁棒性。
核心创新点
1. 带专家引导预训练的决策完备性抽象，解决 RL 早期完备性崩溃问题（冷启动修复）。
2. 带校准不确定性的对象 - 关系隐式世界模型，适配交互式驾驶动力学。
3. 梦境训练 - 高保真测试评估方案，结合 CARLA 与 3DGS 评估，直接解决评估悖论与伪闭环（日志回放）缺陷。
方法简述驾驶日志 + 交互式 Rollout → 令牌化 + 4D 先验（DGGT/VGGT4D）→ 专家蒸馏抽象 → 对象 - 关系世界模型 → 隐式想象 RL → CARLA + 3DGS 评估。
